#  Tienda Tech API

## 🛠️ Tecnologías utilizadas
- **Node.js & Express:** Servidor y rutas web.
- **JavaScript (ESM):** Módulos modernos de JavaScript.
- **Git & GitHub:** Control de versiones.

##  Endpoints Principales
- `GET /api/productos` - Consulta el catálogo de productos.
- `POST /api/productos` - Agrega un nuevo producto al catálogo.
